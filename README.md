# termina-lang.github.io

Landing page of the Termina programming language, served by GitHub Pages at
[termina-lang.github.io](https://termina-lang.github.io/). Plain HTML and CSS,
no build step: pushing to `main` publishes the site.

## Layout

```
index.html    the page
styles.css    brand styles (palette variables at the top of :root)
assets/       logos and hero artwork
```
